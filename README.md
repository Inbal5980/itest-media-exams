# אתר בחינות מתוקשבות עתירות מדיה

אתר מידע לבחינות הבגרות המתוקשבות עתירות המדיה (תשפ"ז): תחומי הדעת, הנחיות היערכות, מכתב ההנחיות של אגף בכיר בחינות, קישורים שימושיים וקבצים מהדרייב לכל תחום. עדכונים חדשים מופיעים בפס "חדש" בראש העמוד.

- לאתר: https://itest-media-exams.sites.tab.bot/
- קישור גיבוי (GitHub Pages): https://inbal5980.github.io/itest-media-exams/

התיקייה tools/ מכילה כלי עזר לרענון רשימת הקבצים מהדרייב (files.json) והוראות לחיבור Apps Script.
